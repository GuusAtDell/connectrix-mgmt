## How to Get Listed

Contributors are added to this file when they:

- Have a **Pull Request merged** into the main branch
- Report a **bug** that leads to a fix (credited in the PR)
- Contribute significant **documentation** improvements
- Provide **tested results** on new switch models or FOS/NX-OS versions

If your contribution was merged but you're not listed here, please open an Issue or PR to add yourself.
